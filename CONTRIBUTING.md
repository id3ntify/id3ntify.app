# Contributing to ID3ntify

Thanks for your interest! Bug reports, ideas and pull requests are all welcome.

## Reporting a problem or suggesting an idea

Use **Help & feedback** in the app, or [open an issue](https://github.com/id3ntify/id3ntify.app/issues/new/choose). For a problem, please include the output of **Copy diagnostics**. It has your versions and settings, with keys and your Windows user name removed.

## Code changes

1. Fork the repository and make your change on a new branch.
2. Build and try it with `build.bat`, or run it from source with `run-from-source.bat` (see the README).
3. Keep changes focused, and describe what you changed and why in the pull request.

By sending a pull request, you agree that your contribution is licensed under the project's licence, the [GNU GPL v3 or later](LICENSE).
